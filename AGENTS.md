# Working on Laurine

- All produced content, documentation, public filenames and new model labels must be in English. Conversation may be in French.
- Keep the README welcoming to sailors: visuals, downloads, scale, materials and assembly. Put development details in docs/DEVELOPMENT.md.
- Keep stable paths. Use Git commits and tags for versions, not new generation directories.
- The full-length hull must remain intact. The horizontal hull/deck joint is intentional.
- Private photographs, videos, reference scans and shopping/account notes belong under private/, which must remain ignored. Never stage them or embed them in public Blender or 3MF files.
- Run fabrication tools only into build/. Review geometry, colours, fits and slicing before replacing files in model/ or print/.
- Keep the source geometry needed by the generator. Do not replace a reviewed print project merely because a newer intermediate file exists.
- Digital checks do not establish that a physical print fits. Keep this distinction in documentation.
